# 时延、吞吐量与带宽计算

|时延|含义|公式/特点|
|---|---|---|
|处理时延|检查首部、差错检测、决定输出链路|通常题目会直接给|
|排队时延|分组在路由器队列中等待转发|最不稳定，和拥塞有关|
|传输时延|把整个分组推送到链路上所需时间|`d_trans = L / R`|
|传播时延|比特在链路上传播所需时间|`d_prop = d / s`|
```
L：分组长度，单位 bit
R：链路传输速率，单位 bit/s
d：链路长度，单位 m
s：传播速度，单位 m/s
```

**端到端时延**：

```
d_nodal = d_proc + d_queue + d_trans + d_prop
```
