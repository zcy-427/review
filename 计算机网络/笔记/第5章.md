## 引论和服务

数据链路层解决的是：**相邻节点之间如何把网络层数据报封装成帧并传输。**

**考试核心**

|概念|必背|
|---|---|
|节点|主机、路由器等设备|
|链路|相邻节点之间的通信通道|
|帧 frame|数据链路层 PDU|
|网卡 NIC|数据链路层功能通常由网卡实现|
|通信范围|相邻节点到相邻节点|

**数据链路层服务**

1. **成帧**：把网络层数据报封装成帧。
2. **链路访问**：共享链路时决定谁能发送。
3. **差错检测和纠正**：如 CRC。
4. **可靠交付**：某些链路层协议可在相邻节点间提供可靠传输。
5. **流量控制**：防止接收方处理不过来。
6. **半双工/全双工通信**。

## 差错检测和纠正

**一句话说明**  
差错检测和纠正解决的是：**接收方如何发现甚至纠正链路传输中的比特错误。**

**1. 基本概念**

发送方发送：

```
数据 D + 差错检测码 EDC
```

接收方检查：

```
收到的数据和 EDC 是否一致
```

常见方法：

- 奇偶校验
- 校验和
- CRC 循环冗余检测

链路层最常考：**CRC**。

**2. CRC 核心思想**

CRC 把比特串看成二进制多项式，使用生成多项式 `G` 做模 2 除法。

考试不用讲多项式，记这个：

> 发送方把数据 D 后面补 r 个 0，用生成多项式 G 做模 2 除法，得到 r 位余数 R，将 D 和 R 一起发送。接收方用同一个 G 去除收到的比特串，若余数为 0，则认为未检测到差错。

其中：

```
r = G 的位数 - 1
```

**3. CRC 计算步骤**

给：

```
D = 数据比特串
G = 生成多项式比特串
```

步骤：

1. 计算 `r = G位数 - 1`。
2. 在 D 后面补 `r` 个 0，得到 `D × 2^r`。
3. 用 G 对补 0 后的比特串做**模 2 除法**。
4. 得到 r 位余数 R。
5. 发送比特串为：

```
D + R
```

**模 2 除法规则**

```
减法不借位
加法不进位
本质就是异或 XOR
```

也就是：

```
1 XOR 1 = 0
1 XOR 0 = 1
0 XOR 1 = 1
0 XOR 0 = 0
```

**4. 例题**

给：

```
D = 101001
G = 1101
```

求 CRC 余数 R 和发送比特串。

第一步：

```
G 位数 = 4
r = 3
```

D 后补 3 个 0：

```
101001000
```

用 `1101` 做模 2 除法，余数为：

```
R = 001
```

所以发送：

```
101001001
```

这个例子是课件里的典型结果，要记住过程形式。

**5. 易错点**

1. `r = G位数 - 1`。
2. D 后面补的是 r 个 0。
3. CRC 除法是 XOR，不是普通减法。
4. 余数必须补足 r 位，不够前面补 0。
5. 发送的是 `D + R`，不是 `D + 0`。
6. 接收方整串除以 G，余数为 0 表示通过。
