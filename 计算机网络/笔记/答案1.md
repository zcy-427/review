**一、概念题**

1. 什么是 socket？网络中标识一个应用进程需要哪两个信息？
	应用层和运输层之间的软件接口；IP+端口号
2. HTTP 为什么通常使用 TCP？
	HTTP 传输 Web 对象，需要可靠、按序的数据传输；TCP 能提供面向连接、可靠传输、按序交付和拥塞控制，所以 HTTP 通常运行在 TCP 之上
3. Cookie 解决 HTTP 的什么问题？
	http的无状态问题，http无法保存用户状态

**二、比较题**

4. 比较非持续 HTTP 和持续 HTTP，至少写 3 点。
	非持续http每请求一个对象就要建立一个连接；持续http多个对象共用一个连接
	非持续http版本为http/1.0 持续http默认http/1.1
	非持续http开销大，要反复握手和创建连接；持续http开销小，减少连接建立开销
5. 比较 SMTP 和 HTTP 在传输方向上的区别。
	smtp是push，http是pull
6. 比较 POP3 和 IMAP 的主要区别。
	pop3简单，常见“下载并删除/保留”
	IMAP支持文件夹、同步、多设备管理

**三、流程题**

7. 写出 DNS 解析 `www.example.com` 的基本过程。
主机向本地 DNS 查询；本地 DNS 依次向根 DNS、顶级域 DNS、权威 DNS 查询，最终获得 `www.example.com` 的 IP 地址，返回给主机并缓存结果。

**五、判断题**

9. 判断：DNS 是网络层协议，主要负责 IP 地址到 MAC 地址的转换。对还是错？为什么？
错误；DNS是数据库系统，用于完成域名到 IP 地址等信息的映射
10. 判断：FTP 使用一个 TCP 连接同时传输命令和文件数据。对还是错？为什么？
错误；使用控制连接传输命令和响应 数据连接传输文件数据
