
**第一梯队：必背**

| 对比                 | 核心区别                                                       |
| ------------------ | ---------------------------------------------------------- |
| TCP vs UDP         | TCP 面向连接、可靠、按序、字节流、有流量/拥塞控制；UDP 无连接、不可靠、不保证按序、面向报文、首部小、时延低 |
| 网络层 vs 传输层         | 网络层：主机到主机；传输层：进程到进程                                        |
| 流量控制 vs 拥塞控制       | 流量控制保护接收方，靠 `rwnd`；拥塞控制保护网络，靠 `cwnd`                       |
| 分组交换 vs 电路交换       | 分组交换共享链路、统计复用、适合突发数据；电路交换先建立连接、资源独占、适合连续业务                 |
| 数据报网络 vs 虚电路网络     | 数据报不建立网络层连接、携带目的地址；虚电路先建立连接、携带 VC 号、路由器维护状态                |
| LS vs DV           | LS 掌握全局拓扑，用 Dijkstra；DV 只与邻居交换距离向量，用 Bellman-Ford          |
| RIP vs OSPF vs BGP | RIP：AS 内、DV、跳数；OSPF：AS 内、LS、Dijkstra；BGP：AS 间、路径向量、策略路由    |
| 交换机 vs 路由器         | 交换机链路层，按 MAC 转发帧；路由器网络层，按 IP 转发分组                          |

**第二梯队：常考**

|对比|核心区别|
|---|---|
|HTTP vs FTP|HTTP 传 Web 对象、无状态、通常一个连接；FTP 传文件、有状态、控制连接和数据连接分离|
|SMTP vs HTTP|SMTP 是 push 推送邮件；HTTP 是 pull 拉取 Web 对象|
|POP3 vs IMAP|POP3 简单下载邮件；IMAP 支持服务器端管理、文件夹、多设备同步|
|非持续 HTTP vs 持续 HTTP|非持续每个对象一个 TCP 连接；持续多个对象复用 TCP 连接|
|Cookie vs Web 缓存|Cookie 维护用户状态；Web 缓存保存对象副本、减少时延和流量|
|递归 DNS vs 迭代 DNS|递归是帮你查到底；迭代是告诉你下一步问谁|
|IP 地址 vs MAC 地址|IP 网络层、32 bit、层次化、用于路由；MAC 链路层、48 bit、扁平化、用于局域网帧转发|
|ARP vs DNS|ARP：IP → MAC；DNS：域名 → IP|

**第三梯队：计算/机制题常配套考**

|对比|核心区别|
|---|---|
|GBN vs SR|GBN 丢弃乱序、累积 ACK、丢一个重传一串；SR 缓存乱序、单独 ACK、只重传丢失分组|
|超时重传 vs 快速重传|超时是等计时器到期；快速重传是收到 3 个冗余 ACK 后立即重传|
|慢启动 vs 拥塞避免|慢启动指数增长；拥塞避免线性增长|
|超时 vs 3 个冗余 ACK|超时认为拥塞严重，`cwnd=1`；3 冗余 ACK 较轻，`cwnd` 降到门限附近|
|CSMA/CD vs CSMA/CA|CD 有线以太网，碰撞检测；CA 无线 WiFi，碰撞避免|
|广播 vs 多播 vs 单播|单播一对一；广播一对所有；多播一对一组|
|封装 vs 解封装|发送端自上而下加首部/尾部；接收端自下而上去首部/尾部|
|转发 vs 路由选择|转发是单个路由器内查表送出口；路由选择是全网计算路径|

**第四梯队：模型/版本对比**

|对比|核心区别|
|---|---|
|OSI vs TCP/IP|OSI 七层、理论参考；TCP/IP 五层、实际互联网使用；TCP/IP 把表示层/会话层并入应用层|
|IPv4 vs IPv6|IPv4 32 bit、首部可变、有校验和、路由器可分片；IPv6 128 bit、固定 40B、无首部校验和、路由器不分片|
|UDP socket vs TCP socket|UDP 无连接，主要按目的 IP+目的端口分用；TCP 面向连接，用四元组标识连接|
|Web 缓存 vs DNS 缓存|Web 缓存缓存 Web 对象；DNS 缓存缓存域名解析记录|
|交换式以太网 vs 共享式以太网|共享式可能碰撞，用 CSMA/CD；交换式全双工基本无碰撞|


|协议|信道假设|新增机制|解决的问题|
|---|---|---|---|
|rdt1.0|信道完全可靠|无需差错控制|理想情况，数据不会错、不丢|
|rdt2.0|数据分组可能出错|校验和、ACK、NAK、重传|检测差错并重传出错分组|
|rdt2.1|ACK/NAK 也可能出错|序号 0/1|区分新分组和重复分组|
|rdt2.2|不使用 NAK|重复 ACK 代替 NAK|只用 ACK 实现确认/否定效果|
|rdt3.0|分组或 ACK 可能丢失|定时器、超时重传|处理丢包和 ACK 丢失|

5. 数据报网络 vs 虚电路网络
6. LS vs DV
7. 交换机 vs 路由器
