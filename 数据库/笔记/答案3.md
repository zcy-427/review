## 题 1

写 SQL：查询每个学生的平均成绩，显示学号和平均成绩。
```sql
select 学号,AVG(成绩)
from 成绩表
group by 学号
```
## 题 2

写 SQL：查询平均成绩大于等于 85 的学生学号。
```sql
select 学号
from 成绩表
group by 学号
having AVG(成绩)>=85
```
## 题 3

写 SQL：查询选修了“数据库原理”的学生学号、姓名和成绩。
```sql
select stu.学号,stu.姓名,gra.成绩
from 学生表 stu,课程表 sc,成绩表 gra
where stu.学号=gra.学号 and sc.课程号=gra.课程号 and sc.课程名='数据库原理'
```
## 题 4

写 SQL：创建视图 `v_female`，查询所有女学生的学号、姓名、性别、班级。
```sql
create view v_female as
select 学号、姓名、性别、班级
from 学生表
where 性别='女'
```
