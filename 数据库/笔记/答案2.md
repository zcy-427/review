## 一、建表与数据维护

### 题 1

创建 `学生表`，要求：

```
学号 CHAR(8)，主键
姓名 VARCHAR(20)
性别 CHAR(2)
年龄 INT
所在院系 VARCHAR(30)
班级 VARCHAR(20)
入学日期 DATE
```

并要求：

```
性别只能是“男”或“女”
年龄在 15 到 30 之间
```


```sql
CREATE TABLE 学生表 (
    学号 CHAR(8) PRIMARY KEY,
    姓名 VARCHAR(20),
    性别 CHAR(2) CHECK (性别 IN ('男', '女')),
    年龄 INT CHECK (年龄 BETWEEN 15 AND 30),
    所在院系 VARCHAR(30),
    班级 VARCHAR(20),
    入学日期 DATE
);
```

---

### 题 2

创建 `成绩表`，要求：

```
学号 CHAR(8)
课程号 CHAR(4)
成绩 INT
学分 INT
```

要求：

```
(学号, 课程号) 为主键
学号为外键，引用 学生表(学号)
课程号为外键，引用 课程表(课程号)
成绩在 0 到 100 之间
```


```sql
CREATE TABLE 成绩表 (
    学号 CHAR(8),
    课程号 CHAR(4),
    成绩 INT CHECK (成绩 BETWEEN 0 AND 100),
    学分 INT,
    PRIMARY KEY (学号, 课程号),
    FOREIGN KEY (学号) REFERENCES 学生表(学号),
    FOREIGN KEY (课程号) REFERENCES 课程表(课程号)
);
```

### 题 12

统计男、女学生各自的人数和平均年龄。


### 题 13

列出选修了一门以上课程的学生学号及其选修门数。

```sql
select 学号,COUNT(*)
from 成绩表
where exists(
select *
from 课程表
where 课程表.课程号 = 成绩表.课程号
)
```

---

### 题 14

统计每一年龄的学生人数，只显示人数大于等于 2 的年龄组，并按人数升序、年龄降序排列。

```sql
select 年龄,COUNT(*)
from 学生表
group by 年龄
having count(*)>=2
order by COUNT(*) ASC,年龄 DESC
```
