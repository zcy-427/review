## 一、建表与数据维护

### 题 1

创建 `学生表`，要求：

```
学号 CHAR(8)，主键
姓名 VARCHAR(20)
性别 CHAR(2)
年龄 INT
所在院系 VARCHAR(30)
班级 VARCHAR(20)
入学日期 DATE
```

并要求：

```
性别只能是“男”或“女”
年龄在 15 到 30 之间
```


```sql
create table 学生表(
学号 char(8) primary key,
姓名 VARCHAR(20),
性别 CHAR(2) check in ('男','女'),
年龄 INT check in (年龄>15 and 年龄<30),
所在院系 VARCHAR(30),
班级 VARCHAR(20),
入学日期 DATE
)
```

---

### 题 2

创建 `成绩表`，要求：

```
学号 CHAR(8)
课程号 CHAR(4)
成绩 INT
学分 INT
```

要求：

```
(学号, 课程号) 为主键
学号为外键，引用 学生表(学号)
课程号为外键，引用 课程表(课程号)
成绩在 0 到 100 之间
```


```sql
create table 成绩表(
学号 CHAR(8) 
课程号 CHAR(4)
成绩 INT check in (成绩>0 and 成绩<100),
学分 INT
)
```
