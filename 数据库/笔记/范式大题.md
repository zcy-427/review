## 1.求候选码

- 列出**只**出现在左边的L，**只**出现在右边的属性R，**同时**出现在左右的属性LR，对于左右两边都没有出现的，直接加入L
- 对L求闭包，如果可以推出R，则L为候选码
- 如果推不出R，就添加LR属性组合，重复直到推出R，则当时的组合为候选码

## 3.分解范式

### 求最小函数依赖集

**1.拆右**：
如果有：

```
A → BC
```

拆成：

```
A → B
A → C
```

例如：

```
AB → CD
```

拆成：

```
AB → C
AB → D
```
**2.左最小**：
如果有：

```
AB → C
```

要判断 A 或 B 是否多余。

判断 B 是否多余：

```
求 A+，看能不能推出 C。
```

如果：

```
A+ 包含 C
```

说明 B 多余，`AB → C` 可以改成：

```
A → C
```

判断 A 是否多余：

```
求 B+，看能不能推出 C。
```

如果 B+ 包含 C，说明 A 多余。

口诀：

```
左边删一个，求闭包；
还能推出右边，就删掉。
```

**3.去自**：对于每一个函数依赖，如果去掉本身，比如对于A->B，如果去掉自己，还是可以通过其他的函数依赖+左边（这里是A）推出B，那么A->B这个函数依赖就可以去掉

对每一条依赖：

```
X → A
```

先暂时删掉它，然后用剩下的依赖求：

```
X+
```

如果还能推出 A，说明这条依赖多余，可以删除。

口诀：

```
删掉一条，看还能不能推出；
能推出，就真删。
```

经过这几步得出最小函数依赖集
