## 1.求候选码

- 列出**只**出现在左边的L，**只**出现在右边的属性R，**同时**出现在左右的属性LR，对于左右两边都没有出现的，直接加入L
- 对L求闭包，如果可以推出R，则L为候选码
- 如果推不出R，就添加LR属性组合，重复直到推出R，则当时的组合为候选码

## 2.范式判断

1.判断是否存在部分函数依赖
2.判断是否存在传递依赖
3.判断函数依赖左边是否都是超键

|概念|特点|
|---|---|
|超键|能推出全部属性，可以有多余属性|
|候选键|没有多余属性的最小超键|

## 3.分解范式

### 求最小函数依赖集

**1.拆右**：
如果有：

```
A → BC
```

拆成：

```
A → B
A → C
```

例如：

```
AB → CD
```

拆成：

```
AB → C
AB → D
```
**2.左最小**：对于函数依赖的左边，看是否可以分割（不是说左边只能有一个），比如AB->C，它可以拆为A->C,B->C，看能不能直接用A就推出B，用B推出C
如果有：

```
AB → C
```

要判断 A 或 B 是否多余。

判断 B 是否多余：

```
求 A+，看能不能推出 C。
```

如果：

```
A+ 包含 C
```

说明 B 多余，`AB → C` 可以改成：

```
A → C
```

判断 A 是否多余：

```
求 B+，看能不能推出 C。
```

如果 B+ 包含 C，说明 A 多余。

口诀：

```
左边删一个，求闭包；
还能推出右边，就删掉。
```

- 3.去自：对于每一个函数依赖，如果去掉本身，比如对于A->B，如果去掉自己，还是可以通过其他的函数依赖+左边（这里是A）推出B，那么A->B这个函数依赖就可以去掉


经过这几步得出最小函数依赖集
