# 索引
## 1. 什么是索引？

索引是为了加快数据查询速度而建立的数据结构。

类比：

```
书的目录 = 索引
书的正文 = 数据表
```

没有目录，查内容要一页一页翻；有目录，可以快速定位。

考试定义：

```
索引是数据库中为了提高查询效率而建立的一种辅助存储结构。
```

---

## 2. 索引优点

```
提高查询速度；
加快排序、分组和连接操作。
```

---

## 3. 索引缺点

```
占用额外存储空间；
插入、删除、修改数据时需要维护索引，可能降低更新速度。
```

---

## 4. 聚簇索引和非聚簇索引

| 类型    | 含义                             |
| ----- | ------------------------------ |
| 聚簇索引  | 数据行的物理存储顺序与索引顺序一致              |
| 非聚簇索引 | 索引顺序与数据物理存储顺序不一致，索引中保存指向数据行的指针 |

必背：

```
一个表通常只能有一个聚簇索引；
一个表可以有多个非聚簇索引。
```

因为数据的物理顺序只能有一种。

# 存储过程与触发器

## 存储过程

### 1. 存储过程是什么？

存储过程是预先编译并保存在数据库中的一组 SQL 语句。

考试定义：

```
存储过程是存储在数据库服务器端、可以被反复调用执行的一组预编译 SQL 语句集合。
```

### 2. 存储过程优缺点

**优点**:
```
模块化编程；
基于函数限制访问表格；
减少网络通信流；
保证一致性；
提高执行效率；
增强安全性；
便于集中管理业务逻辑。
```

**缺点**：
```
编程语言功能差
与编程环境集成不够
移植性差
```
### 3. 简单例子

```sql
CREATE PROCEDURE GetStudentByDept
    @Dept VARCHAR(20)
AS
BEGIN
    SELECT Sno, Sname
    FROM Student
    WHERE Dept = @Dept;
END;
```

调用：

```sql
EXEC GetStudentByDept '软件工程';
```

## 触发器

### 1.触发器是什么？

触发器是当数据库表发生插入、删除、修改等事件时，由系统自动执行的一段程序。

考试定义：

```
触发器是定义在表上的一种特殊存储过程，当对表执行 INSERT、DELETE 或 UPDATE 操作时自动触发执行。
```

### 2. 触发器作用

```
维护数据完整性；
实现复杂业务规则；
自动记录日志；
实现级联操作。
```

### 3. 触发器类型

|类型|含义|
|---|---|
|INSERT 触发器|插入数据时触发|
|DELETE 触发器|删除数据时触发|
|UPDATE 触发器|修改数据时触发|
|AFTER 触发器|操作执行后触发|
|INSTEAD OF 触发器|替代原操作执行|
