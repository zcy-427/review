# 磁盘调度算法

## 一、FCFS：先来先服务

规则：

> 按请求到达顺序访问磁道。

优点：简单、公平。  
缺点：磁头可能来回大幅移动，效率低。

例子：

```
当前磁头：50
请求序列：80, 20, 90
```

访问顺序：

```
50 → 80 → 20 → 90
```

总移动：

```
|80-50| + |20-80| + |90-20|
= 30 + 60 + 70 = 160
```

## 二、SSTF：最短寻道时间优先

规则：

> 每次选择距离当前磁头最近的请求。

关键词：

```
谁离我最近，先访问谁。
```

优点：平均寻道时间较短。  
缺点：远处请求可能长期得不到服务，产生“饥饿”。

例子：

```
当前磁头：50
请求序列：80, 20, 55
```

当前 50，最近的是 55：

```
50 → 55 → 80 → 20
```

总移动：

```
|55-50| + |80-55| + |20-80|
= 5 + 25 + 60 = 90
```

## 三、SCAN：扫描算法 / 电梯算法

规则：

> 磁头像电梯一样，沿一个方向移动，服务沿途请求；到达磁盘一端后，再反向移动。

关键词：

```
一路扫到底，再返回。
```

如果题目说磁道范围是 `0~199`，方向向大磁道移动，那么 SCAN 会先往大磁道方向服务，直到磁盘末端 `199`，再反向。

例子：

```
磁头：50
请求：20, 60, 90
方向：向大磁道
范围：0~99
```

访问顺序：

```
50 → 60 → 90 → 99 → 20
```

注意：  
SCAN 通常要走到磁盘端点，再反向。

## 四、C-SCAN：循环扫描

规则：

> 磁头只按一个方向服务，到达磁盘一端后，直接回到另一端，再继续同方向服务。

关键词：

```
从小到大排序，磁头开始向增方向zou
```

如果方向向大磁道：

```
当前 → 大磁道请求 → 磁盘最大端 → 磁盘最小端 → 小磁道请求
```

优点：

```
等待时间更均匀。
```
