## 题 1：打印室排队

某办公室有一台打印机和一个打印任务缓冲区，最多可存放 `N` 个打印任务。  
多个用户进程可以提交打印任务，打印进程从缓冲区中取任务并打印。要求：

```
1. 缓冲区满时，用户进程不能再提交任务；
2. 缓冲区空时，打印进程不能取任务；
3. 多个用户进程和打印进程访问缓冲区时必须互斥；
4. 打印机一次只能打印一个任务。
```

请用 PV 操作描述用户进程和打印进程。

```c

打印机(){
	while(1){
		申请缓冲区
		判断是否为空：是的话就退出
		打印
		释放缓冲区
	}
}

用户(){
	while(1){
		申请缓冲区
		判断是否为满：是的话就退出
		提交
		释放缓冲区
	}
}
```

提示：这题表面是打印室，实质是有限缓冲区 + 独占设备。

## 题 2：候诊室叫号

医院有一个候诊室，最多容纳 `M` 名病人。  
病人到达后，如果候诊室未满，则进入候诊室等待；如果候诊室已满，则在外面等待。  
医生每次从候诊室叫一名病人看诊。要求：

```
1. 候诊室人数不能超过 M；
2. 没有病人时，医生不能叫号；
3. 病人进入候诊室和医生叫号都要修改候诊人数，必须互斥；
4. 医生一次只能给一个病人看诊。
```

请用 PV 操作描述病人进程和医生进程。

## 题 3：单车维修站

某共享单车维修站有：

```
一个待修区，最多放 K 辆坏车；
一个已修区，最多放 L 辆好车；
多个搬运工负责把坏车送入待修区；
多个维修工从待修区取坏车维修，修好后放入已修区；
多个配送员从已修区取好车送走。
```

要求：

```
1. 待修区满时，搬运工不能再放坏车；
2. 待修区空时，维修工不能取坏车；
3. 已修区满时，维修工不能放好车；
4. 已修区空时，配送员不能取好车；
5. 待修区和已修区分别是临界资源，访问时要互斥。
```

请设置信号量，并写出搬运工、维修工、配送员的 PV 操作。

这题比生产者消费者多一层，很适合练综合。
